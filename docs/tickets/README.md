# ScoutLink delivery board

One ticket represents one demonstrable vertical feature. The engineering lead
creates tickets; implementation moves them through the statuses below; the QA
role supplies independent release evidence.

## Status flow

`Proposed -> Ready -> In progress -> In QA -> Done`

Do not start a second product feature while the current ticket is `In progress`
unless the user explicitly changes priorities or the first ticket is externally
blocked.
